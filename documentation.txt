═══════════════════════════════════════════════════════════════════
  WHAT THIS BOT DOES (simple version)
═══════════════════════════════════════════════════════════════════

  Every week Polymarket asks:
  "How many times will Elon Musk tweet this week?"

  There are 30 brackets like: 280-299, 300-319, 320-339...
  Each bracket sells YES shares at a price reflecting probability.

  Example:
    340-359 YES shares at 22¢ = market thinks 22% chance
    If Elon tweets 340-359 times → shares pay out $1 each (+354%)
    If he doesn't → shares pay out $0 (-100%)

  Our edge:
    We use a Poisson statistical model to estimate the REAL probability.
    If our model says 57% and market says 22% → we buy.
    We sell when market catches up to our price, or at resolution.

═══════════════════════════════════════════════════════════════════
  HOW THE TRADING LOGIC WORKS
═══════════════════════════════════════════════════════════════════

  STEP 1: GET TWEET COUNT
  ┌─────────────────────────────────────────────────────────┐
  │  Poll Twitter every 5s                                  │
  │  weekly_count = lifetime_count - BASELINE_LIFETIME      │
  │  BASELINE_LIFETIME = lifetime tweets at market start     │
  └─────────────────────────────────────────────────────────┘

  STEP 2: RUN MODEL
  ┌─────────────────────────────────────────────────────────┐
  │  For each future hour until May 5:                      │
  │    base_rate = HOURLY_RATES[hour]  (tweets/hour)        │
  │    × burst_factor   (are we in a tweet storm?)          │
  │    × accel_factor   (is rate speeding up?)              │
  │    × burst_decay    (effect fades over 2 hours)         │
  │                                                         │
  │  lambda = sum of all adjusted rates                     │
  │  P(bracket) = Poisson PMF sum over bracket range        │
  └─────────────────────────────────────────────────────────┘

  STEP 3: CALCULATE EDGE
  ┌─────────────────────────────────────────────────────────┐
  │  raw_edge  = model_probability - market_ask_price       │
  │  true_edge = raw_edge - spread - fee - slippage         │
  │                       - model_error_buffer              │
  │            = raw_edge - 8.5%                            │
  │                                                         │
  │  Example:                                               │
  │    model says 57%, market ask 22%                       │
  │    raw_edge  = 57% - 22% = 35%                          │
  │    true_edge = 35% - 8.5% = 26.5%  ← profitable        │
  └─────────────────────────────────────────────────────────┘

  STEP 4: ENTRY CHECKS (all must pass)
  ┌─────────────────────────────────────────────────────────┐
  │  ✅ raw_edge > 15%                                      │
  │  ✅ true_edge > 5%                                      │
  │  ✅ spread < 2.5¢ (low price) or < 10% (high price)     │
  │  ✅ hours_left > 2                                      │
  │  ✅ if hours_left < 6: need 25%+ edge                   │
  └─────────────────────────────────────────────────────────┘

  STEP 5: POSITION SIZING (Kelly Criterion)
  ┌─────────────────────────────────────────────────────────┐
  │  Kelly % = (odds × edge - loss_prob) / odds             │
  │  bet size = Kelly% × 0.25 × bankroll   (quarter Kelly)  │
  │                                                         │
  │  Example at 26.5% edge, 22¢ price:                      │
  │    odds = (1/0.22) - 1 = 3.55x                          │
  │    kelly = (3.55×0.265 - 0.735) / 3.55 = 6.7%          │
  │    quarter kelly = 6.7% × 0.25 = 1.7%                  │
  │    bet = 1.7% × €1000 = €17... ×2 (half kelly) = €34   │
  └─────────────────────────────────────────────────────────┘

  STEP 6: EXIT CONDITIONS
  ┌─────────────────────────────────────────────────────────┐
  │  TAKE PROFIT:  price reaches 2× entry price             │
  │  STOP LOSS:    price drops to 50% of entry price        │
  │  EDGE GONE:    true_edge drops below 5%                 │
  │  SAFETY:       Twitter blind >10min with positions      │
  │  SAFETY:       <6h left AND position down 30%+          │
  │  SAFETY:       count surpasses bracket's high           │
  │  MARKET END:   close everything at resolution           │
  └─────────────────────────────────────────────────────────┘
